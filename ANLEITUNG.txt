TINY WOO WEBSITE – ANLEITUNG (ORDNER-VERSION)
=============================================

1. HOCHLADEN AUF GITHUB (EINMALIG)
---------------------------------
1. ZIP entpacken (Rechtsklick -> "Alle extrahieren").
2. Den entpackten Ordner "website" öffnen.
3. Darin ALLES markieren (Strg + A).
4. github.com/RensbourroTaki/TinyWoo -> "Add file" -> "Upload files"
5. Alles ins Feld ziehen -> "Commit changes".
6. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, / (root) -> Save
7. Nach 1–2 Minuten: https://rensbourrotaki.github.io/TinyWoo/

WICHTIG: index.html muss direkt neben README.md liegen, NICHT in einem Unterordner "website".
Falls eine alte index.html da ist: wird einfach überschrieben.


2. WAS IST WO?
--------------
   index.html            Die Seite. Nicht anfassen.
   inhalt.js             <-- HIER änderst du alles (Songs, Games, Links, Texte, Spiel)
   ANLEITUNG.txt         Diese Datei
   assets/logo/          tinywoo-logo.png
   assets/games/         Game-Bilder (rocket-trump-menu.jpg)
   assets/music/         OGGs (noch leer)
   assets/game/          Grafiken fürs Fadenkreuz-Spiel (noch leer)
   fonts/                Schriften. Nicht anfassen.
   js/, tokens/, styles.css   Technik. Nicht anfassen.


3. ETWAS ÄNDERN (z.B. neuer Song)
--------------------------------
A) Datei hochladen
   - Auf GitHub in den Ordner gehen, z.B. assets -> music
   - "Add file" -> "Upload files" -> OGG reinziehen -> "Commit changes"

B) In inhalt.js eintragen
   - Auf GitHub inhalt.js anklicken
   - Rechts oben auf das STIFT-Symbol klicken
   - Zeile ergänzen, z.B. unter "musik":
       { title: 'Jungle Hangar', artist: 'Tiny Woo', src: 'assets/music/jungle-hangar.ogg', duration: 201 },
   - Oben rechts "Commit changes" -> nochmal "Commit changes"

C) 1–2 Minuten warten, Seite neu laden (Strg + F5).


4. DIE WICHTIGSTEN STELLEN IN inhalt.js
--------------------------------------
   links.discord   -> dein Discord-Einladungslink (alle Discord-Buttons)
   links.email     -> Kontakt-Adresse (Footer, About, Press)
   socials         -> Social-Buttons. href = Link. Zeile löschen = Button weg.
   musik           -> Playlist. Reihenfolge = Reihenfolge im Player.
   games           -> Games. featured: true = groß auf der Startseite.
                      trailer = YouTube-Link, presse = Fakten + Screenshots.
   presse          -> Press-Seite: Intro, Studio-Fakten, Downloads.
   spiel           -> Fadenkreuz-Spiel: Titel, Sekunden, Munition, Grafiken.
   texte           -> Überschrift, Texte, Laufband, Footer.

Alles in inhalt.js ist kommentiert. Beispiele stehen direkt dabei.


5. TIPPS GEGEN FEHLER
--------------------
   - Texte immer in 'einfachen Anführungszeichen'.
   - Hinter jedem Eintrag ein Komma.
   - Apostroph im Text (z.B. don't)? Dann den Text in "doppelte" Anführungszeichen setzen.
   - Dateinamen klein, ohne Leerzeichen/Umlaute: jungle-hangar.mp3
   - Pfad in inhalt.js muss EXAKT zum Dateinamen passen (auch Groß/Klein!).
   - Seite plötzlich leer? Dann ist in inhalt.js ein Komma/Anführungszeichen kaputt.
     Auf GitHub -> inhalt.js -> "History" -> letzte Version wiederherstellen,
     oder schick mir die Datei.


6. HIGHSCORES
------------
   Werden im Browser jedes Besuchers gespeichert (jeder sieht seine eigenen).
   Gemeinsame Liste für alle = kommt mit dem Admin/CMS später.
